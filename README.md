## 如何本地运行

1. 确保已安装 Python 3.10 或更高版本。
2. 克隆仓库并进入项目目录：

   ```bash
   git clone https://github.com/weidi0904/ai-learning.git
   cd ai-learning
   ```

3. 运行下面的命令，验证 `main.py` 中的 `add` 函数：

   ```bash
   python -c "from main import add; print(add(1, 2))"
   ```

正常情况下，终端会输出 `3`。本项目仅使用 Python 标准库，无需安装额外依赖。
