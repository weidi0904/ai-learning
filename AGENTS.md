## Scope

This project is a small Python learning/demo repository.

## Rules

- Keep changes small and directly tied to the requested task.
- Do not add third-party dependencies unless the standard library is clearly insufficient.
- Prefer simple Python code that beginners can understand.
- Run a minimal Python verification command after code changes.
- Keep generated caches, virtual environments, build outputs, secrets, and local AI/tooling files out of Git.
